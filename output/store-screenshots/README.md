参考：Downloads/1.png〜5.png。配色、見出しの段組み、端末の配置、人物イラストを参考に再構成しました。

## 完成画像

各フォルダに5枚、7言語 × 2端末で70枚あります。

- `iphone/{ja,en,ko,zh-Hant,es,pt-BR,id}/`：1320 × 2868 px。iPhone 17 Pro Max の画面を使用。
- `iphone-duo/{ja,en,ko,zh-Hant,es,pt-BR,id}/`：1398 × 2034 px。iPhone Duo のメインディスプレイの画面を使用。

PNG / RGB / アルファチャンネルなし。`index.html` で一覧できます。

1. `01-record-anywhere.png`：どんな状況でも録音
2. `02-tap-to-record.png`：画面を見ずにタップで録音
3. `03-slide-to-stop.png`：スライド式の停止ボタン
4. `04-share-recordings.png`：他アプリへの共有
5. `05-recording-list.png`：シンプルな録音一覧

## 実画面と再現部分

`raw/` は撮影したままの56枚のアプリ画面です。待機・録音・一覧・共有の4画面を両端末・7言語で撮影しています。実際のアプリの View と、スクリーンショット専用のサンプル録音データを使いました。録音表示の時間とレベルは固定しています。

完成画像にはコードで作成した見出しと汎用の白い端末フレームを合成しています。Duo は縦横比に合わせて構図を調整しました。3枚目の拡大スライダーはアプリのラベルと形状をもとに描画しています。

4枚目の共有パネルは、OS 側の共有拡張に端末の日本語が残るため、参考画像に合わせたパネルをコードで再現して各言語の表記を統一しています。コピー・ファイルへの保存というアプリで利用できる機能を示したものです。OS の共有画面そのものの未加工スクリーンショットは `raw/` に分けてあります。

人物イラストは built-in imagegen で参考画像から背景と文字を除去した素材を使用しました。元画像や実画面の文字を画像生成で翻訳する方法は使っていません。使用プロンプトは `Tools/StoreScreenshots/illustration-prompt.txt`、見出しは `copy.json`、再現共有パネルの表記は `share-copy.json` にあります。

## 確認

両端末で撮影テスト成功。現在の iOS 27 シミュレーターでは繁体字の実画面も正常に描画されました。各言語の見出しと拡大ラベルの幅は `typography-checks.json` で機械確認しています。

このフォルダは画像の制作成果物です。App Store Connect へのアップロードや公開は行っていません。
