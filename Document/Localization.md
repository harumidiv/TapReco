# ローカライズ

日本語、英語、韓国語、繁体字中国語、スペイン語、ポルトガル語（ブラジル）、インドネシア語に対応。端末／アプリの言語設定に従い、未対応言語では英語にフォールバックする。

既存の左から右のレイアウトとスライド方向を維持できる言語を選んだ。想定市場は日本、米国・カナダ・オーストラリア、韓国、台湾・香港、スペイン・中南米、ブラジル、インドネシア。言語で広告配信の可否を判定しない。

AdMob の国・地域制限を確認したうえで選定したが、言語対応は国ごとの広告配信や収益を保証しない。App Store Connect の販売地域やストア文言は別途設定する。

- 国・地域制限：https://support.google.com/admob/answer/6163675?hl=en
- 対応地域（アカウント登録対象）：https://support.google.com/admob/answer/16451422?hl=en
- 広告の同意管理：https://developers.google.com/admob/ios/privacy

確認日：2026-11-13。現状の広告実装は ATT のみで、UMP による同意管理は未実装。EEA・英国・スイスなど、同意管理が必要な地域へ公開する際は UMP 等の実装と AdMob 管理画面のメッセージ設定が必要。この変更の対象はローカライズであり、広告リクエスト処理や販売地域は変更しない。

## リソース

- `Localization/Localizable.xcstrings`：画面、UIKit のラベル、エラー案内、新規録音名、ウィジェット、App Intent。アプリとウィジェットで共有。
- `Localization/InfoPlist.xcstrings`：表示名、マイク・位置情報・トラッキングの権限説明。
- `Localization/*.lproj/AppShortcuts.strings`：Siri の起動フレーズ。iOS 16 を維持するため、このテーブルのみ `.strings` を使用。

日本語のキーを維持し、SwiftUI の動的な文言は `LocalizedStringKey`、UIKit と録音名は `NSLocalizedString` を使用する。録音ファイル名・保存済みのタイトル・日時の保存形式は変更しない。

日本語を含む画像は日本語では既存画像を表示し、ほかの言語では同じ寸法で翻訳テキストを表示する。操作用の固定幅ラベルには縮小設定を追加し、広告バッジは既存の幅に収まる短い表記を使う。

## 確認

`testLocalizedResourcesAreBundledForAppAndWidget` で両ターゲットの翻訳リソースとショートカットの変数を検証する。`testLocalizedOnboarding` で7言語の起動画面を確認し、各3ページのスクリーンショットを XCTest の添付として残す。

### 今回の検証結果

- iOS Simulator 向けアプリ・ウィジェットのビルド成功。
- ユニットテスト6件成功。7言語の翻訳と Siri フレーズの組み込みを確認。
- iPhone 17 と iPhone SE（第3世代、375pt幅）で7言語の初回説明画面の UI テスト成功。SE では待機画面も撮影し、開始ボタンの動作を確認。
- 日本語・英語・韓国語・スペイン語・ポルトガル語（ブラジル）・インドネシア語のスクリーンショットで、説明画面と待機画面の文字の収まりを確認。
- 繁体字は、初回の iOS 26.3.1 シミュレーターではシステム表示も含めて文字化けした。その後のストア画像撮影では、iOS 27.0 の iPhone と iOS 27.1 の iPhone Duo の実画面で正常な描画を確認できた。実機での確認は未実施。
